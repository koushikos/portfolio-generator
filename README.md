## 📝 Project Description

Personal Portfolio Website Generator is a simple and intuitive web application that allows users to create a professional portfolio website without any coding knowledge. Users can fill out a form with their personal information—including their name, bio, skills, projects, and contact details—and the application dynamically generates a clean, responsive, and professional portfolio page in real-time.

This project is perfect for students, beginners, and professionals who want to quickly showcase their work and skills online without the hassle of writing code or learning web development.

---

## ✨ Features

- **User-Friendly Input Form** — Simple and intuitive form to enter personal information
- **Automatic Portfolio Generation** — See your portfolio update in real-time as you type
- **Sections for About, Skills, Projects, and Contact** — All essential portfolio sections included
- **Clean and Responsive UI** — Looks great on desktop, tablet, and mobile devices
- **Built with Pure HTML, CSS, and JavaScript** — No frameworks or dependencies required
- **Instant Preview** — View changes immediately without refreshing the page

## 🚀 How to Run the Project

Follow these simple steps to get started:

1. **Clone the repository**
   ```bash
   git clone https://github.com/koushikos/portfolio-generator.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd portfolio-generator
   ```

3. **Open `index.html` in your web browser**
   - Simply double-click the `index.html` file
   - Or right-click and select "Open with" → your preferred browser

That's it! Start filling out the form and watch your portfolio come to life.
